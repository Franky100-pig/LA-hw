# LA-hw

Original Linear Algebra practice sets with full worked solutions. It can be used with the LA Helper to strengthen your Linear Algebra knowledge.

All problems are self-written mimicking the form of MIT 18.06 (Gilbert Strang) — no school or course materials are included. If there are similar questions, those are just coincidences. Set 1 covers determinant properties, row operations, cofactor structure and Cramer's rule, with proof-style reasoning questions. Set 2 applies row echelon form to the determinant: tracking swaps and scalings, spotting singularity before computing, and a proof that a pivot in every row is exactly $\det A \neq 0$. Set 3 turns those tools onto vectors — linear independence, bases and dimension — where the unifying idea is that independence is a question about solutions: $Ac = 0$, $Ac = b$ and $Bc = v$ are the same three tools answering three different questions. It closes the loop with the equivalence $\det A \neq 0 \iff$ independent columns $\iff$ trivial null space $\iff$ invertible, and includes two applied problems (polynomials as coefficient vectors, and whether experimental data is collinear). Set 4 steps back from computation to concepts: what makes a set a vector space or a subspace (the three-step test), why each axiom exists, span as closure, bases as coordinate systems, and the kernel–image pair with rank-nullity — deliberately light on computation, building the vocabulary that later problem sets will combine.
